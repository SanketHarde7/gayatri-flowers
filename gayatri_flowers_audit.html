CSS fixes — add these to style.css
High impact
Heading polish — balance, kerning, optical sizing
Large headings need text-wrap:balance to prevent single orphan words on last line. font-optical-sizing and font-kerning sharpen Cormorant at display sizes.
h1, h2, h3 { text-wrap: balance; font-kerning: normal; font-optical-sizing: auto; font-feature-settings: "kern" 1, "liga" 1, "calt" 1; }
High impact
Body copy is too small
Base font is 0.88–0.9rem (~14px). Anything below 15px on body text reads as a mobile afterthought on desktop. Bump to 0.96rem minimum.
Now
.hero-description, .flower-content p { font-size: 0.88rem }
Fix
.hero-description, .flower-content p { font-size: 0.96rem }
Medium
Counter numbers need tabular figures
When your JS animates 0 → 10,000 the digits jump width because Cormorant uses proportional figures by default. Add font-variant-numeric to the stat numbers.
.stat-number { font-variant-numeric: tabular-nums; font-feature-settings: "tnum"; }
Medium
Section tags / eyebrow text too tight
.section-tag and .eyebrow use font-size 0.65rem. That's 10.4px — below the accessibility comfort threshold. Use 0.72rem minimum and slightly reduce letter-spacing from 0.26em to 0.20em.
Now
font-size: 0.65rem;
letter-spacing: 0.26em
Fix
font-size: 0.72rem;
letter-spacing: 0.20em
Low
Missing italic font pairing for DM Sans
Cormorant italics are loaded but DM Sans italic is not in the Google Fonts import. Add ital axis or the browser will synthesise italic — looks bad.
<!-- Replace current Google Fonts link --> family=DM+Sans:ital,wght@0,300;0,400;0,500;0,600;1,400

High
Hero image has no width/height attributes
Without explicit width and height, the browser can't reserve layout space while loading — causes a layout shift (bad CLS score). Add width="1920" height="1080" to the hero <img>. Do the same for all images.
High
Missing <link rel="preload"> for hero image
Hero has fetchpriority="high" but no preload hint in <head>. Adding one reduces LCP by ~200–400ms.
<link rel="preload" as="image" href="assets/hero-bg.jpg" fetchpriority="high">
High
No skip-to-content link for keyboard/screen reader users
Add as the very first element inside <body>:

Medium
All images should use modern formats (WebP/AVIF)
Use <picture> with AVIF + WebP fallbacks for hero and gallery images. Typical saving: 40–65% smaller files, faster load on mobile.
